I want to add a prominent bidding module inspired by the interaction pattern shown in the reference screenshot.

Do NOT copy Outbid.lol's branding, exact design, code, text, logo, or proprietary assets.

Recreate the useful UX concept for UpnDownBid's own weekly campaign system.

==================================================
1. MAIN BID MODULE
==================================================

At the top of the current campaign section, create a prominent interactive module.

Example:

Campaign #13
Ends in 5D 18H 24M

Then:

BID FOR #1   [ − ]   $355   [ + ]

The amount must be interactive.

The user can:
- tap +
- tap -
- directly edit the amount
- use a numeric input/stepper

Minimum bid:

$5

The amount must never go below the current minimum bid.

==================================================
2. DYNAMIC RANK PREVIEW
==================================================

As the user changes the bid amount, immediately calculate the projected ranking.

Example:

BID FOR #1
[-] $355 [+]

If $355 would currently rank #3:

YOUR PROJECTED RANK

#3

If $1,250 would currently rank #1:

YOUR PROJECTED RANK

#1

Do NOT falsely say "Claim #1" unless the entered amount would actually currently place the product at #1.

Use dynamic text:

If projected rank is #1:

CLAIM #1 FOR $1,250

If projected rank is #3:

BID $355 → PROJECTED #3

If projected rank is #10:

BID $50 → PROJECTED #10

15. IMPORTANT: EFFECTIVE BID
==================================================

The ranking is NOT based only on the entered owner bid.

Calculate:

Effective Bid =
Owner Bid
+
Community Support
-
Penalties

Example:

Product A

Owner Bid:
$1,000

Support:
+$300

Penalties:
-$50

Effective Bid:
$1,250

Therefore, the bid module must calculate projected ranking against EFFECTIVE BID.

For a new owner bid:

Projected Effective Bid =
New Owner Bid
+
Existing Community Support
-
Existing Penalties

For a completely new listing:

Projected Effective Bid =
Owner Bid
