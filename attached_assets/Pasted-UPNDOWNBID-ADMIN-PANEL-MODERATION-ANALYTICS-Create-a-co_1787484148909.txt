UPNDOWNBID — ADMIN PANEL + MODERATION + ANALYTICS

Create a completely separate, secure ADMIN PANEL for UpnDownBid.

IMPORTANT:
This is an ADMIN-ONLY area.

Normal public users must never have access to the admin panel.

Do not change the public no-login experience.

==================================================
1. ADMIN LOGIN
==================================================

Create:

/admin

The admin panel must require secure authentication.

Do NOT use the public owner login for admin access.

Admin authentication must be separate.

Use secure password hashing and sessions.

Never expose admin credentials.

Add server-side authorization to EVERY admin API endpoint.

Never rely only on hiding admin UI elements.

==================================================
9. SUSPEND VS DELETE
==================================================

Prefer:

SUSPEND

for temporary moderation.

Suspended products:

- disappear from active rankings
- cannot receive new Boosts
- cannot receive Push Downs
- cannot participate in active campaigns
- remain visible to admins
- retain historical transactions

Permanent removal should be reserved for confirmed violations.

Do NOT destroy financial history.
